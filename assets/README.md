# Assets Overview

> This subdirectory contains essential resources and documentation for the Clarity classification framework, including
> datasets, configuration files, and usage guides.

## Directories

- [**literature/**](literature): Contains research papers and articles relevant to the Clarity classification task.
- [**presentation/**](presentation): DEPRECATED - Previously held presentation materials.
- [**prompts/**](prompts): Stores prompt templates used for LLM classification experiments.
- [**taxonomy/**](taxonomy): Contains different versions of the clarity taxonomy in various formats (CSV, JSON, PNG).
